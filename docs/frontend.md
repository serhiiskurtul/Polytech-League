# Polytech League - Frontend

Ця частина репозиторію містить клієнтську частину (UI) платформи Polytech League. Вона забезпечує взаємодію користувачів із системою, перегляд рейтингів, реєстрацію на турніри та управління змаганнями.

## 🛠️ Технологічний стек

* **Бібліотека:** React 19
* **Мова:** TypeScript
* **Збирач (Bundler):** Vite
* **Маршрутизація:** React Router (v7)
* **Форми та валідація:** React Hook Form + Yup
* **Real-time зв'язок:** @microsoft/signalr
* **Графіки:** Recharts
* **Додатково:** Axios, react-hot-toast/react-toastify, jspdf (для генерації звітів), chess.js.

## 📁 Структура проєкту

* `src/` — основний код додатку:
  * `components/` — перевикористовувані UI компоненти.
  * `pages/` — сторінки додатку (Турніри, Рейтинги, Профіль гравця тощо).
  * `services/` — сервіси для взаємодії з бекенд API (через Axios).
  * `hooks/` — кастомні React хуки.
  * `utils/` — допоміжні функції (helpers).
* `public/` — статичні ресурси (іконки, зображення).
* `vite.config.ts` — конфігурація збирача Vite.

## 🚀 Запуск локально

### Передумови
* Встановлений [Node.js](https://nodejs.org/) (рекомендується версія 18 або вище).

### Кроки для запуску:

1. Перейдіть до папки frontend:
   ```bash
   cd frontend
   ```

2. Встановіть залежності:
   ```bash
   npm install
   ```

3. Створіть файл `.env` на основі наявного конфігу та вкажіть URL вашого бекенду (наприклад, `VITE_API_URL=http://localhost:5000`).

4. Запустіть сервер для розробки (Development server):
   ```bash
   npm run dev
   ```

Проєкт буде доступний у браузері зазвичай за адресою `http://localhost:5173`.

### Створення Production збірки
Для створення оптимізованої збірки для продакшену виконайте:
```bash
npm run build
```
Готові статичні файли з'являться у папці `dist/`.

## 🌍 Розгортання (Deployment)
Проєкт налаштований для автоматичного розгортання на платформі **Vercel** (присутні файли `vercel.json` та аналітика `@vercel/analytics`).
