# Polytech League

Ласкаво просимо до офіційної документації проєкту **Polytech League** — платформи для управління спортивними турнірами та рейтингами гравців.

## 📚 Навігація по документації

Нижче наведено посилання на детальну документацію по різних частинах проєкту:

* 🎯 **[Огляд проєкту](./docs/project-overview.md)** — загальна інформація про платформу, її можливості та функціонал.
* 🖥️ **[Frontend (Клієнтська частина)](./docs/frontend.md)** — документація по користувацькому інтерфейсу (React, TypeScript, Vite).
* ⚙️ **[Backend (Серверна частина)](./docs/backend.md)** — документація по API та базі даних (.NET, PostgreSQL, Clean Architecture).
* 🐳 **[Інфраструктура та розгортання](./docs/infrastructure.md)** — як запустити проєкт через Docker, моніторинг (Grafana, Prometheus).
* 🔌 **[Публічний API](./docs/public-api.md)** — інструкція для інтеграції та отримання даних про спортивні події для зовнішніх розробників.
